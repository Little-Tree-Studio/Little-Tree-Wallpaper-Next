## Our Commitment

Little Tree Wallpaper is an open-source project. We are committed to providing a welcoming, respectful and constructive community for everyone, regardless of background, identity, experience level or point of view.

## Expected Behavior

- Use respectful, inclusive and professional language.
- Focus criticism on code, documentation, data, designs and technical decisions, not on people.
- Explain disagreements in good faith and prefer evidence-based discussion.
- Respect project boundaries, licenses, privacy and security requirements.
- Help keep issue reports and pull requests focused and reproducible.

## Unacceptable Behavior

- Harassment, discrimination, threats, intimidation or personal attacks.
- Publishing private or sensitive information without permission.
- Trolling, deliberate disruption, impersonation or bad-faith participation.
- Submitting malware, credentials, unauthorized copyrighted material or personal data.
- Evading project moderation or using project infrastructure to target others.

## Enforcement

Project maintainers may edit or remove inappropriate content, close discussions, reject contributions or restrict participation when this code is violated. Reports will be handled as privately as practical.

For security and privacy issues, do not open a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Scope

This code applies to project spaces, repositories, issue trackers, pull requests, community channels and public interactions when someone is representing the project.
